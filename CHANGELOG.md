# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),

## [0.1.0] - 2026-02-24

### Added
- Boilerplate inicial con Electron, Vite, React y TypeScript.
- Configuración para build de instaladores Windows con `electron-builder`.
- Base de datos SQLite integrada usando `better-sqlite3`.
- Esquema de base de datos mínima: tabla `Producto`.
